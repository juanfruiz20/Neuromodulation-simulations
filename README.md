# Neuromodulation-simulations
# Generative AI-Based Acceleration of 3D Transcranial Ultrasound Simulations

This repository contains the main code developed for the Bachelor’s Thesis project:

**Generative AI-Based Acceleration of 3D Transcranial Ultrasound Simulations**

The project explores the use of deep learning surrogate models to accelerate three-dimensional transcranial ultrasound stimulation (TUS) acoustic simulations. Conventional numerical solvers such as k-Wave can accurately estimate intracranial acoustic pressure fields, but their computational cost limits their use in fast or interactive planning workflows. This work evaluates U-Net and conditional generative adversarial network (cGAN) architectures for predicting 3D acoustic pressure fields from skull and transducer geometry.

## Project Overview

The objective of this project is to develop and evaluate AI-based models capable of approximating 3D acoustic pressure fields generated by transcranial ultrasound simulations.

The complete workflow includes:

1. Generation of synthetic skull geometries and transducer configurations.
2. Numerical simulation of 3D acoustic pressure fields using k-Wave.
3. Training of U-Net and cGAN-based surrogate models.
4. Evaluation using image similarity, focal accuracy, Dice overlap, beam-profile, and computational time metrics.
5. Generation of qualitative figures and thesis plots for model comparison.

The final goal is to assess whether deep learning models can be used as fast pre-planning tools for TUS simulation workflows.

## Main Components

### Dataset Generation

The `dataset_generation/` folder contains the scripts used to create synthetic skull geometries, generate simulation inputs, and split the dataset into training, validation, and test sets.

### Source Code

The `src/` folder contains the main reusable code of the project.

* `src/data/`: dataset loading and data handling utilities.
* `src/models/`: 3D neural network architectures, including the U-Net generator and 3D discriminator.
* `src/losses/`: task-specific loss functions designed to improve focal accuracy, beam consistency, pressure gradients, and peak localization.
* `src/metrics/`: validation metrics used to compare model predictions with k-Wave ground truth simulations.
* `src/training/`: training loops, checkpoint handling, logging utilities, learning schedules, and trainer functions.
* `src/utils/`: general utility functions, including reproducibility tools.
* `src/visualization/`: scripts for generating qualitative prediction figures, failure case images, and visual callbacks during training.

### Thesis Figures

The `thesis_figures/` folder contains scripts used to generate the final figures and plots included in the thesis, such as:

* Ablation study plots.
* Violin plot comparisons.
* Model comparison plots.
* Basic result plots.
* Computational time analysis.
